\section{Formal Metric Definitions}

The Canonical Structural Compression Ratio (SCR) is defined as the structural information preserved per token:

\begin{equation}
    SCR = \frac{SI(E)}{|T(E)|}
\end{equation}

where $SI(E)$ is the Structural Information score, defined as:

\begin{equation}
    SI(E) = \alpha O + \beta \log(1+D) + \gamma R + \delta F + \epsilon C
\end{equation}

Where:
\begin{itemize}
    \item $O$ = operator count
    \item $D$ = AST depth
    \item $R$ = parent-child relations
    \item $F$ = function scope count
    \item $C$ = canonical equivalence preservation bonus
\end{itemize}
